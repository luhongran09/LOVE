# 足迹：Vue + Gin 第一阶段

这是在 Footprint 仓库内新增的独立应用，入口为 `web/` 和 `server/`。原版 `frontend/`、`backend/` 与原有 Docker 配置仍保留。

## 已实现

- 首位用户创建双人空间，通过一次性邀请码加入第二位用户（24 小时有效，最多两人）。
- 密码使用 bcrypt 哈希，登录使用保存在数据库中的随机会话；浏览器通过 HttpOnly、SameSite Cookie 登录，不把凭据放在照片 URL 中。
- 两人共同查看、上传、修改和删除空间内照片，原图接口也校验权限。
- 多图上传（每批最多 20 张、100MB，单张最多 20MB），保留原文件；支持 JPG / PNG / GIF。
- 自动读取照片 EXIF 日期与 GPS，也可在编辑页手动补拍摄日期、地点和经纬度，或点击地图选点。
- 按月展示时间轴，支持年份、地点、标题和备注搜索，地点相册与 Leaflet 地图。
- 沿用原版的深色渐变、毛玻璃与顶部导航，支持深浅色切换、照片墙／时间轴切换、地图折叠和手机底部导航。
- 同一坐标的照片合并为带数量的标记，点击后可从缩略图列表选择照片；地理参考标签与实际照片标记使用不同样式。
- 上传及照片详情弹窗支持 Tab 焦点循环、Esc 关闭和背景滚动锁定。
- ZIP 完整备份：照片原文件 + 日期、地点、坐标、标题、备注；支持恢复、重复跳过和失败回滚。
- 适配桌面和手机，提供加载状态、空状态和操作错误提示。

## 本地运行

需要 Go 1.24+、C 编译器（SQLite 驱动需要 CGO）、Node.js 22+ 和 npm。

终端一，在仓库根目录：

```bash
cd server
go mod download
go run .
```

终端二，在仓库根目录：

```bash
cd web
npm ci
npm run dev
```

访问 http://localhost:5173 。Vite 将 `/api` 请求代理到 Gin 的 `127.0.0.1:8080`。

首次打开选择“创建空间”，设置自己的账号和密码。进入“双人空间”，生成邀请码；另一半在登录页选择“接受邀请”，用不同名字创建账号。

## 构建后由 Gin 提供网页

```bash
cd web
npm ci
npm run build
cd ../server
go build -o footprint .
./footprint
```

访问 http://localhost:8080 。请从 `server/` 目录启动，静态文件默认读取 `../web/dist`。

数据库和原图默认在 `server/data/`，已加入 Git 忽略。重启服务会保留数据。

## Docker

在仓库根目录：

```bash
docker compose -f compose.v2.yml up -d --build
```

访问 http://localhost:8080 。使用 `album-data` 持久化卷保存数据。公网部署时在反向代理配置 HTTPS，并把 `COOKIE_SECURE` 设置为 `true`，按实际域名设置 `APP_ORIGIN`。首次创建空间前不要把空实例暴露给他人。

## 配置

Go 程序读取环境变量，不自动加载 `.env`：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `LISTEN_ADDR` | `127.0.0.1:8080` | 监听地址；容器中使用 `0.0.0.0:8080` |
| `DATA_DIR` | `./data` | 数据库和原图所在目录 |
| `COOKIE_SECURE` | `false` | HTTPS 部署设为 `true` |
| `APP_ORIGIN` | 空 | 反向代理场景的浏览器 Origin，例如 `https://album.example.com` |

## 当前范围与兼容性

- 新版独立使用 `server/data/album.db`，不会自动读取旧版 SQLite、JSON 或浏览器离线数据。旧版数据迁移尚未实现。
- 新版 API 针对双人相册设计，不是旧版所有 `/api` 的兼容替代；旧小程序也尚未适配。
- HEIC/HEIF、视频、缩略图、手机自动备份、离线同步、多家云存储、AI 和原版其他生活工具不在本阶段。
- 地图自带 Natural Earth 离线地理轮廓，详细街道使用 OpenStreetMap 联网瓦片。断网时仍能查看地理轮廓及照片标记；离线轮廓不含街道细节。中文地点名称可手动填写，本阶段不依赖付费地图 API。坐标应使用 WGS84，未接入高德坐标转换。
- 没有 EXIF 拍摄日期时使用上传当天；没有 GPS 时不会自动推断地点。
- 备份恢复上限为 250MB（包括解压后的总量），仅支持本版本导出的 ZIP，不包含账号、密码和会话。恢复照片归操作账号所有，空间内两人均可查看和编辑。
- 备份用于照片内容恢复。要原样迁移账号和登录信息，应停服务后复制整个 `DATA_DIR`。
- 本阶段适合两人的小型相册；照片列表一次加载全部元数据，尚未提供大规模相册分页与缩略图优化。

## 本轮迁移更新

当前已从单照片版升级为多图回忆版。**最新功能与剩余差异以 [迁移进度](MIGRATION-PROGRESS.md) 为准**，本文件前面的第一阶段列表和限制是初版范围，以下变化已覆盖相应旧说明：

- 新增回忆分组、封面顺序、1/4/9 宫格、分类标签、浏览式多图详情与事件级时间轴。
- 新增城市归类、主动地点查询、真实 3D 地球、护照、成就、路线回放、情侣及生活工具。
- 当前支持 WebP，新增 `/api/photos/:id/thumb` 缩略图；账号与原图权限继续生效。
- 新版 v2 ZIP 保存多图关系和共同清单，兼容 v1 ZIP 与原版后台全量 ZIP。旧版缺失的远程照片和旧密码不自动导入。
- `BACKUP_MAX_MB` 可配置 1–8192MB，默认 250MB，同时限制导出和恢复；每段回忆最多 200 张照片，每次上传最多 20 张。
- 可配置 `LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL` 使用兼容模型服务；不配置时使用本地故事草稿。密钥只从服务端环境读取。
- 自动更新采用每 10 秒 revision 检查和窗口聚焦刷新；主要页面已拆成真实 Vue Router 组件。
- 首次升级已有照片库前自动生成 `before-memory-migration-*.sqlite3`；原图片文件不改写。

## 地图与已有账号配对更新

- 默认详细底图恢复为原项目的高德瓦片；可切换 OpenStreetMap 或离线轮廓。加载失败时尝试备用源，工具条支持重试和查看全部足迹。在线地图会向对应地图服务请求当前视野瓦片。
- 原图 GPS、地点查询与数据库统一保留 WGS84；高德显示时本地转换为 GCJ-02，地图选点再转换回 WGS84。已有数据不批量改写，旧版导入的坐标仍按备份原值保留。
- 图钉根据旅行、美食、情侣分类；聚合按回忆计数，点击可展开或预览回忆，缩略图有空间访问校验。
- 已注册的两个独立账号可在“双人空间”使用邀请码重新配对；预览确认、密码校验、回忆与清单合并规则详见迁移进度报告。
- `/api/library` 返回去掉照片备注的足迹索引及成员；`GET /api/memories/:id` 按需读取完整回忆。旧版列表接口仍保留。
- 验证增加 `cd web && npm test`，覆盖地图坐标转换；CI 同时运行该检查。
