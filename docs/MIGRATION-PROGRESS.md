## 验证边界

- 已通过 Go 集成与竞态测试、静态检查，以及 Vue 类型检查和生产构建。
- 使用临时数据库完成 Firefox 端到端验收：10 张照片归入一条回忆、九宫格 +N、封面与排序、类别标签、城市、共同心愿重载持久化、护照／成就／回放／报告／故事、恋爱起始日，以及 390px 手机布局。
- 浏览器中实际创建并渲染了 WebGL 地球，而不是仅检查入口存在。
- 另使用 33 段临时回忆验证 30／3 翻页无重复、390px 分页布局；验证远端心愿更新后自动刷新且保留草稿、409 冲突后重试，以及会话失效返回登录页。
- 新增验收：高德瓦片接口实际 HTTP 200，Firefox 实际加载高德街道图；分类图钉、回忆聚合预览、在线／离线切换、390px 控件布局；禁用缩放过渡，避免首次自动定位时底图与标记短暂处于不同缩放级别；两个已有账号预览后配对、双份心愿保留与详情照片备注按需读取。
- 坐标测试覆盖北京参考点、多次往返精度以及新加坡、日本、韩国等海外点不误偏移；浏览器中验证切换底图后选点仍保留原 GPS 位置，模拟屏蔽在线请求后两级回退及标记保留；低精度离线轮廓仅用于区域判定与备用显示，不提供测绘精度。
- 地点服务协议以模拟外部响应测试；公网地点查询受网络和 OpenStreetMap Nominatim 可用性影响。只在用户主动查询时访问，限制每秒一次。
- 未使用真实付费模型密钥验收模型请求；默认本地故事已验证。配置模型后，生成故事会将当前空间最近至多 20 段回忆的标题、地点、日期与备注发送给该模型服务。
- 时光胶囊的日期控制是产品层的约定阅读体验，未提供内容加密或对同空间成员的秘密隔离。
- Docker 已实际发起构建，前端阶段完成，但 Go 基础镜像下载超过 20 分钟后停滞，本次已中止；尚未完成镜像构建和容器启动验收。

## 尚未完成／仍是基础迁移

1. **完整中英文国际化**：当前仍主要是中文，并非原版所有文字的双语切换。
2. **PWA 与相册离线编辑**：尚无完整 Service Worker 缓存、IndexedDB 离线编辑队列及冲突回放；离线地图不等于相册可离线工作。
3. **云存储和多数据库**：当前仍是本地文件 + SQLite，未迁移 OSS、COS、七牛、S3、GCS、Azure、PostgreSQL 等适配与配置检测后台。
4. **微信小程序**：旧小程序未适配新版接口。
5. **HEIC/HEIF 与直链导入**：目前支持 JPG/PNG/GIF/WebP，HEIC 需要转换；未开放网络图片直链批量抓取。
6. **大图库全链路性能**：照片墙与时间轴已使用服务端分页，每页 30 段；首页改用不含照片备注的单份索引，详情按需获取，避免完整照片数据重复传输。地图、护照、统计仍加载全量基础元数据和回忆备注，尚未改为按视野分片或虚拟列表。
7. **原版精细视觉**：3D 使用国家级低精度轮廓，不等于原版中国地级市浮雕；护照、勋章和情侣工具已接真实数据，但未逐像素还原原版全部排版、字段与粒子／礼花效果。二维聚合采用网格逻辑，尚未复制原版 MarkerCluster 的动画和蜘蛛展开。
8. **后台与账号迁移**：设置页已含成员、配对、日期、内容备份及导出，但并非原版完整管理后台。旧 Python 用户密码格式不导入，需要在新版使用账号；旧云端直链图片未打包时会明确拒绝导入，避免生成缺图回忆。

## 数据保障

- 升级不会覆盖照片原文件。首次从旧版单照片库升级且已有照片时，在 DATA_DIR 下生成 `before-memory-migration-*.sqlite3`。
- v2 内容备份不包含登录账号与会话；要原样搬迁整台服务，应停服务复制整个 DATA_DIR。
- 旧版导入只能使用本地完整 ZIP；备份缺照片、文件无效、跨空间照片关联、超限或重复引用等情况会失败回滚。
- 运行数据、编译产物与 TypeScript 构建缓存已添加忽略规则；本次没有代替用户提交或修改 Git 暂存区。

## 已有账号配对说明

1. 双方都需要处于独立空间；已配对账号先在设置中解除原配对。
2. 一方生成邀请码；另一方登录自己的账号，在“双人空间 → 已有账号？加入 TA 的空间”粘贴邀请码。
3. 预览双方姓名、回忆及照片数，输入当前账号密码，再确认合并。邀请码有效期 24 小时、单次使用。
4. 照片原文件、所属账号、回忆顺序和封面不变；清单合并时同 ID 且内容相同的去重，双方分别修改的保留两份。恋爱起始日等同名空间设置沿用受邀目标空间的值；目标没有的字段从原空间补入。
5. 双方数据在预览后发生变化时拒绝确认，需要重新预览；异常格式或清单合并超限时整体回滚。配对成功后双方可查看、修改共同内容。
